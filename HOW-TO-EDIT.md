# Как добавить услугу в блок «What I do»

Карточки услуг на главной берутся из файла **`texts/home.yml`**. Править вёрстку не нужно: новая карточка встаёт в сетку сама, все карточки одного размера.

## Шаги

1. Откройте `texts/home.yml` (на GitHub: файл → значок карандаша).
2. Найдите раздел `what_i_do:` → `cards:` (Ctrl+F → `what_i_do`).
3. Скопируйте последний блок из двух строк и вставьте **под ним**, с теми же отступами:

   ```yaml
       - title: "Название услуги"
         text: "Короткое описание в одно-два предложения."
   ```

4. Сохраните (на GitHub: **Commit changes**). Netlify сам пересоберёт сайт за пару минут.

## Готовый пример

```yaml
  cards:
    - title: "Lead flows"
      text: "Requests from the website, email and messengers land in one place, qualified and assigned."
      color: "#FFF1C7"
    # ... остальные карточки ...
    - title: "Reporting"
      text: "Dashboards that show leads, response time and sales in one place."
```

## Цвет карточки

Поле `color:` необязательно. Если его нет, цвет подбирается автоматически по кругу из четырёх цветов сайта: жёлтый, зелёный, розовый, сиреневый.

Хотите свой цвет, добавьте третью строку, например `color: "#FFF1C7"`. Цвета сайта:

| Цвет | Код |
| --- | --- |
| Жёлтый | `#FFF1C7` |
| Зелёный | `#E3EEDD` |
| Розовый | `#FBE0D9` |
| Сиреневый | `#E8E4F7` |

## Порядок и удаление

- Карточки идут в том же порядке, что и в файле: хотите поменять местами, переставьте блоки.
- Чтобы убрать услугу, удалите её блок целиком (обе-три строки).

## Чтобы ничего не сломать

- Не трогайте слова слева от двоеточия (`title:`, `text:`, `color:`) и отступы в начале строк. Все блоки должны начинаться с одинакового отступа.
- Текст оставляйте в кавычках `"..."`. Внутри используйте типографские кавычки “ ” или апостроф ’, а не обычные `"`.
- Если после правки сайт не обновился, откройте в Netlify раздел **Deploys**: там будет видна ошибка (обычно лишняя кавычка или сбитый отступ).
